Tinfox weapon sheets: one ChatGPT prompt per file.

Start with prompts/01-pistol.txt: attach characters/sheets/01-guard.png (for the style) and paste the file.
For all the others: attach the guard sheet AND the approved pistol sheet, so the
weapons share one look. 02-pistol-silenced relies on the pistol sheet directly.

Side views always point the muzzle to the right. The generator needs the grip
and the muzzle clearly visible: it will export them as named points for the game.

Names and sizes come from Tinfox (src/data/weapons.json).
Save the approved sheets in weapons/sheets/ with the same numbers (01-pistol.png, ...).
